# AI Automation Toolkit

A lightweight Python toolkit for building AI-powered automation workflows, content processing tools, and productivity utilities.

[![Tests](https://github.com/tranoanh12r218/ai-automation-toolkit/actions/workflows/tests.yml/badge.svg)](https://github.com/tranoanh12r218/ai-automation-toolkit/actions/workflows/tests.yml)

## Features

- Clean and normalize text
- Truncate text safely
- Read and write text files
- List files using glob patterns
- Split text into manageable chunks
- Generate UTC timestamps
- Simple utilities for automation workflows
- Automated testing with GitHub Actions
